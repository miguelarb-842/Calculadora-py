# Calculadora

Calculadora en Python con operaciones básicas y avanzadas (suma, resta, multiplicación, división, potencia, raíz).

## Estructura del proyecto

- `services/` — Lógica de cada operación matemática
- `util/` — Utilidades y validaciones de entrada
- `main.py` — Punto de entrada del programa

## Cómo ejecutar

\`\`\`bash python main.py \`\`\`

## Documentación

La documentación generada con pdoc está disponible en la carpeta `docs/`.
Para verla localmente:

\`\`\`bash start docs/index.html\`\`\`

## Requisitos

- Python 3.x
